# Workspace Drag-Drop Plugin - Usage Guide

## 功能说明

这个插件允许用户通过拖拽文件夹到侧栏来快速添加工作区。

## 使用方法

1. **打开文件资源管理器**，找到你想要添加为工作区的文件夹
2. **拖拽文件夹**到应用左侧的侧栏区域（工作区列表区域）
3. **释放鼠标**，系统会自动创建一个新的工作区

## 视觉反馈

- 当你拖拽文件夹到侧栏上方时，会显示一个半透明的覆盖层
- 覆盖层包含：
  - 虚线边框
  - 文件夹图标
  - 提示文字："拖拽文件夹到此处" / "Drop folder here"
  - 操作说明："创建工作区" / "Create workspace"

## 注意事项

1. **仅支持文件夹**：目前只处理第一个拖拽的项目
2. **需要 Electron 环境**：此功能依赖于 Electron 暴露的文件路径，在纯浏览器环境中无法使用
3. **自动验证**：系统会自动验证路径的有效性，如果失败会显示错误信息

## 故障排除

### 问题：拖拽没有反应

**可能原因**：
- 拖拽的不是文件夹（可能是文件）
- 不在 Electron 环境中运行
- 侧栏处于折叠状态

**解决方法**：
- 确保拖拽的是文件夹而不是文件
- 确认应用在 Electron 环境中运行
- 展开侧栏后再尝试拖拽

### 问题：创建工作区失败

**可能原因**：
- 文件夹路径无效
- 权限不足
- 工作区名称冲突

**解决方法**：
- 检查文件夹是否存在且可访问
- 查看错误提示信息
- 尝试选择其他文件夹

## 技术实现

- 使用原生 HTML5 Drag and Drop API
- 监听全局 drag 事件
- 从 Electron 的 File 对象中提取完整路径
- 调用现有的 `ctx.workspaces.create()` API 创建工作区

## 多语言支持

- 中文（简体）
- 英文

语言会根据应用的当前语言设置自动切换。
